# 项目 AgentMd 维护 🥺👉👈

项目下的 agent.md是项目的长期提示词，不要把什么阿猫阿狗都写进来，回头弄得所有的 AI 进来都要读一坨屎进去污染内容和思路。😖🙏

高变化度的除了项目结构就不要写了，项目结构也不要写太多，写个大概就行了，目录结构和文件名都可以随时改的，如果你目前有变化就更新一下就行了。😣🤞

Agentmd 没什么格式要求，你自己设计，怎么方便后边人理解怎么来，原来的版本也不用遵循，你认为每个项目适合咋写就咋写。🥹✌️

主要就说明白，项目干啥的？大概的业务和关系是啥，一些简单的运行命令，一些特殊长期要求，项目结构大概列一列，帮后面 AI 快速入个门就够了，别写絮絮叨叨的。🥺😣👋
