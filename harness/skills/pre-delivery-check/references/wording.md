# 中文表达与用词

共同要求见全局第 9 节。改写保留事实与条件，脚本匹配只作提示，人检查整句。

## 1. 整句示例

以下均为虚构例子，只示意写法。

<!-- wording:examples:start -->
| 问题 | 改前 | 改后 |
| --- | --- | --- |
| 动作藏在名词里 | 对订单同步失败问题的处理已完成 | 我改了错误处理；断网后保留失败记录，恢复连接后可以重试 |
| 主语不清 | 相关异常已被进行处理 | 导入程序跳过格式错误的记录，并写明文件名与行号 |
| 事实压成口号 | 改动完成，检查通过，待你确认 | 修改已完成。你可在订单列表筛选退款记录，查看金额与状态 |
| 对称句代替依据 | 不是页面不行，而是数据不行 | 页面与接口一致，但退款样例应为80元，接口返回100元 |
| 无依据的赞同 | 这个判断非常深刻 | 两条记录的订单编号与付款时间相同，确实重复 |
| 日常进度过长 | 本次实现已进入最终验证阶段 | 大头弄完啦，还差试一次重复退款 😼 |
| 夸大完成 | 全部搞定 | 本机改好了，线上还没更新 |
| 损失被情绪盖过 | 终于找到问题啦！ | 同一笔退款减了两次，退30元却记成60元。我先查受影响订单 |
| 重复结尾 | 综上，进一步提升了稳定性和可维护性 | 删除；前文已有结果，无新信息 |

## 3. 资料范围

- [Linguistic Differences between AI and Human Comments in Weibo，CCL 2025](https://aclanthology.org/2025.ccl-1.64/) 比较了中文微博评论的文体特征。它说明一组文本存在表达差异，不能把个别词或标点当成通用的写作判定标准。
- [Linguistic features of AI mis/disinformation，2025](https://www.nature.com/articles/s41467-025-67145-1) 研究特定中文文本中的表达模式；结果受文本类型和模型影响，不直接推导日常回复的词语禁令。
- [中文“AI 味”是怎样被训练出来的？，2026-07-08](https://guzhaolin.art/blog/chinese-ai-prose-style) 是作者的资料整理和写作实践，提醒区分可看到的表达问题与未经证实的成因。这里采用检查整句、保留依据的做法，不把作者推测写成模型原理。

这些资料用于整理表达建议。不能据此断定所有模型先用英文思考，也不能承诺一份提示词能消除以后所有不自然的中文；是否好读仍看实际文字。
