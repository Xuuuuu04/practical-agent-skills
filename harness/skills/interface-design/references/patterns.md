# 场景与资料

例子用于判断页面形式，不代替实际业务规则。

## 1. 设计取舍示例

| 场景 | 选择与原因 |
| --- | --- |
| 客服查工单、看问题、回复 | 列表先给判断信息，标签与回复围绕工单组织；缓存和同步放维护入口 |
| 连续扫看几十条工单 | 短预览用侧面板，保留列表筛选与位置 |
| 长篇回复、比较附件或分享 | 独立详情页，支持直接打开与所属业务入口 |
| 边看列表边编辑 | 面板允许操作背景；模态面板会中断操作，不因位置在右边就更合适 |
| 取消未提交编辑 | 按保存方式保留或放弃输入 |
| 已提交或已发生的业务 | 按状态提供撤回或更正，操作记录在业务对象附近 |
| 提交超时 | 结果未知，查询后再决定重试 |
| 密集数据与品牌展示 | 前者重扫描与比较，后者按主题表现，不共用一套装饰布局 |
| 公文预览与导出 | 用确认模板，不将文档字体扩展到按钮与表单 |

卡片形状不能证明页面由 AI 制作，清理装饰也不能拆散同一业务的信息。组件库先用主题配置，局部修改不更换整套技术。

## 2. 可操作性检查

以下数字来自 WCAG 2.2；检查适用条件与例外，几项通过不等于整个产品符合标准。

| 项目 | 条件 |
| --- | --- |
| 文字对比度 | 一般文字至少 4.5:1，标准定义的大字至少 3:1；例外见 1.4.3 |
| 控件与状态 | 必要边界和状态标记按 1.4.11 检查，错误不能只用颜色表达 |
| 点击范围 | 2.5.8 的 AA 要求至少 24×24 CSS 像素或满足间距等例外，44 像素不是全部网页的 AA 要求 |
| 窄屏与放大 | 正文与表单可读可用；二维布局的例外见 1.4.10 |
| 模态弹窗 | 合理初始位置，Tab 限于弹窗，关闭或 Escape 退出后返回合理位置；未保存内容按业务处理 |

尊重 `prefers-reduced-motion`，动画不传递唯一信息。WCAG 2.3.3 属于 AAA，不写成全部 AA 条件。

## 3. 参考资料

查阅日期：2026-10-03。优先参考维护中的一手说明，更新日期与正式标准的状态分别记录。

- [GOV.UK：完成多个任务](https://design-system.service.gov.uk/patterns/complete-multiple-tasks/) 与[确认结果页](https://design-system.service.gov.uk/patterns/confirmation-pages/)：任务分组、进度和完成后的去向。按业务使用，不要求每个短操作另开结果页。
- [Ant Design：抽屉](https://ant.design/components/drawer-cn/)：当前任务中的补充内容和临时操作。组件支持多层抽屉，不等于所有产品都适合多层操作。
- [Ant Design：定制主题](https://ant.design/docs/react/customize-theme-cn/) 与[字体](https://ant.design/docs/spec/font-cn/)：统一主题变量、组件配置、字体用途和中文屏幕阅读。查项目实际版本，不直接套网页上的最新 API 或固定字号。
- [Carbon：Typography](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview)：页面标注更新于 2026-09-29，区分工作界面和展示内容的字体安排。采用按用途设样式的方法，不要求使用 IBM 的字体和配色。
- [W3C：WCAG 2.2 快速参考](https://www.w3.org/WAI/WCAG22/quickref/) 与[弹窗操作模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)：对比度、键盘、点击范围和窗口操作。检查适用条件与例外，示例代码不能代替实际检查。
- [W3C：中文排版需求](https://www.w3.org/TR/2026/DNOTE-clreq-20260901/)：2026-09-01 的工作组说明草稿，用于查中文字体、标点和换行问题；仍在完善，不作为已经确定的公文标准。
- [NN/g：Modal & Nonmodal Dialogs](https://www.nngroup.com/articles/modal-nonmodal-dialog/)：2017 年的基础研究说明，用于理解中断操作的代价；不把发布时间写成近期，也不据此统一规定所有业务的页面形式。
