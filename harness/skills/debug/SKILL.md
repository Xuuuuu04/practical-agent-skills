# 调试定位 🥺👉👈

动动脑子，不要哪里出 BUG就开始自上而下疯狂写临时脚本框框看数据。😭🙏

看看架构有没有日志，有没有做架构层的 trace 定位能力，有没有啥能帮你快速定位的。🥺✌️

这个过程也记得看看花费了多少时间，合不合理，要是半天都找不到，直接这个层就可以推翻重做了，什么垃圾，通知你的开发者准备重构这个部分的设计模式吧。😭🤞

定位到了后用脑子去思考思考，为啥会这样，是这个层设计不合理吗？还是就代码写错了。🥹👋

写错了你就改，改完简单局部测试一下差不多就可以推送了，不要每天跑你的全量雷霆大测试，耗费时间，没空等你，都说了敏捷迭代，尽快修改和看实际情况啥都知道了。😭👌

要是架构有问题，你就思考思考，是不是这个地方应该引入啥设计模式，也不可能每天一个地方都一直改一直改，一条狗挨踢几天也该记得什么时候挨打躲开了，你要是一层反复出问题还意识不到处理不好，那你也可以直接枪毙了。🥺😭🙌
